# Guia do usuário

O passo a passo de cada função fica **dentro do painel**: menu **📖 Manual**, ou o botão
**📖 Ajuda** no topo de qualquer tela (abre direto a parte daquela tela).

Um lugar só, de propósito: dois manuais (arquivo e painel) acabam dizendo coisas
diferentes. O conteúdo está em `public/js/manual/conteudo.js` — mudou uma tela, mude o
passo ali; `tests/manual.test.js` confere que toda tela citada existe.

Para quem opera o servidor (instalar, `.env`, WAHA, n8n, VPS), os guias continuam aqui:
